sol发币

实战

创建一个账户

solana-keygen new --no-outfile

创建一个新账户，同时会生成助记词。

spl-token create-token

创建一个新的代币（Token）。它会生成一个代币的 Mint Address（铸造地址），之后可以用来铸造（mint）代币，也可以用于代币的管理（如冻结、销毁等操作）。

solana config set --url https://api.devnet.solana.com

设置网络，测试网，开发网，主网

solana balance

查看当前账户的资金

solana airdrop 1

获取空投

solana config get

查看配置

spl-token transfer <token-identifier> <amount> qif3CSuotK2hTrkaEE9Bht2nzANNeayGnyZace15UtP --allow-unfunded-recipient --fund-recipient
