一个 dex 对应一个池子的全数据 开 2 个 grpc 数据流

token 数据字节定位

  1. // 101, 181 Whirlpools
  2. // 400, 432 Raydium amm
  3. // ray clmm 73, 105
  4. // solfi 2664 2696
  5. // lifinity_v2 254 286
  6. // meteora pool 40 72

数据库如何写

  1. 数据要全 解析各种事件啥的 重点是每一个池子的初始化池子的 tx
  2. 1-> n 多交易发送 （盲狙） 合约还是要写的
  3. key 值按照 A-> B 来写
